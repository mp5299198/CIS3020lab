Reflection on Building This Website

Creating this multi‑page Legend of Zelda fandom website has been a great opportunity to practice layout design, navigation structure, and consistent styling across multiple pages.

I chose the Royal Hyrule theme because the deep navy and gold palette reflects the regal atmosphere of Hyrule Castle.

What I Learned

  • How to use a shared external CSS file
  • How to create a responsive layout
  • How to design consistent navigation and footers
  • How to apply color theory
  • How to structure content for readability

Challenges and Solutions

Ensuring mobile readability required careful use of flexible containers and media queries.

Maintaining visual consistency was solved by using shared classes like .container and .box.
